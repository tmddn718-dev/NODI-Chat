# 개인정보·동의·세션 리플레이 설정 가이드

## 동의 흐름
- **첫 진입**에 안내 창이 떠요: ①가상 일정(실제 캘린더·메일 영향 없음) ②**입력한 문장은 AI(Groq)에 전송되니 개인정보 금지** ③익명 사용 데이터(선택). 수집 항목·미수집 항목·사용 도구·보존 기간·철회 방법·문의처를 "무엇을 어떻게 수집하나요?"에서 보여줘요.
- 버튼은 두 개예요: **동의하고 시작** / **동의하지 않고 사용**. 거부해도 모든 핵심 기능(회의 만들기·추천·확정·피드백)을 그대로 써요.
- 동의 전에는 **PostHog로 아무 요청도 보내지 않고**, 익명 ID도 만들지 않아요(자동화 테스트·브라우저 네트워크 확인 완료).
- 동의 분리 구조: 저장되는 동의 값은 `{ policyVersion, analytics, replay, decidedAt }`예요. **`replay`는 항상 `false`**(세션 리플레이를 수집하지 않아서 화면에 선택지를 두지 않았어요). 나중에 리플레이를 도입하면 별도 동의 항목으로 추가하세요.
- 문구·수집 항목이 바뀌면 `src/prototype.ts`의 `consentPolicyVersion`을 올려요 → 모든 사용자가 다시 선택해요.

## 철회
설정 → **익명 사용 데이터 → 철회하기**. 철회하면 ①마지막 상태 이벤트(`analytics_consent_updated`, 상태와 정책 버전만) 1회 전송 ②이후 **새 이벤트 수집 중단** ③브라우저의 익명 ID 삭제. 다시 동의하면 **새 ID**가 만들어져 이전 기록과 이어지지 않아요.
> PostHog에 이미 저장된 이전 이벤트는 철회로 지워지지 않아요. 삭제 요청은 운영자가 PostHog에서 처리해야 해요(익명 ID는 사용자가 알 수 없으므로 개별 삭제 요청을 받기 어려운 점을 안내문에 밝히는 걸 권해요).

## 익명 식별
- 로그인이 없어서 **무작위 UUID**(`crypto.randomUUID()`)를 익명 ID로 써요. 이름·이메일과 `identify` 하지 않고, IP는 PostHog 설정(*Discard client IP data*)으로 저장하지 않아요.
- 앱의 익명 ID = PostHog `distinct_id`. **서버 DB에는 익명 ID를 저장하지 않아요**: DB에는 실행(run) ID만 있고, 이 ID는 흐름 한 번마다 새로 만들어져 피드백과의 최소 연결 고리로만 써요.
- **수명**: 동의한 뒤 만들어져 브라우저 `localStorage`에 있다가, 철회하거나 브라우저 저장소를 지우면 없어져요. 화면 회전·리사이즈로는 바뀌지 않아요. 실험군은 이 ID로 정해져서 새로고침해도 유지돼요.

## 수집하지 않는 정보
이름·이메일·전화번호·회사명, 실제 캘린더 내용, **입력 문장 원문**, Groq 프롬프트·응답, API 키·토큰·쿠키 값, 피드백 자유 의견 원문(분석 이벤트로는 절대 안 가요). 일반 서버 로그에도 대화 내용과 키를 남기지 않아요(테스트로 검증).

## 서버 쪽으로 가는 개인정보
- **대화 문장은 AI 처리를 위해 Groq로 전송돼요.** 이 사실을 동의 안내 창과 시작 화면에 밝혔어요. 서버는 문장을 저장하지 않고 로그에도 남기지 않아요.
- 피드백 자유 의견(선택, 300자)은 서버 저장소(Supabase 또는 로컬 파일)에만 저장돼요. 화면에 다시 보여주지 않고, PostHog로 보내지 않아요. "개인정보를 쓰지 말아 주세요" 안내를 입력창 아래에 표시해요.
- 필수 기능을 위한 **세션 쿠키**(`nodi_session`, HttpOnly)는 로그인 대신 가상 작업 공간을 구분하는 데 써요. 분석 용도 쿠키는 쓰지 않아요.

## 세션 리플레이: 기본 OFF, 이 버전에서는 구현하지 않음
지시서의 기준("마스킹이 실제 렌더링에서 확인되기 전에는 켜지 않는다")에 따라 **리플레이를 켜지 않았어요.** 이 앱은 대화 영역·참석자 이름·일정 등 자연어와 가상이라도 사람 이름이 화면에 많이 나와서, 완전한 마스킹을 지금 보장하기 어려워요. 그래서 명시적 익명 이벤트만 수집해요(`posthog-js`도 설치하지 않았어요).
나중에 도입하려면 **모두** 충족해야 해요:
- [ ] 별도 동의 항목(`replay`) 추가, 동의 전 SDK 초기화 금지, 철회 시 즉시 중지
- [ ] 모든 입력창·대화 영역·참석자/일정 DOM 마스킹 또는 차단, 네트워크 요청·응답 본문 캡처 끄기
- [ ] 설정 화면은 항상 차단
- [ ] 실제 렌더링에서 마스킹이 작동하는지 QA 항목으로 확인
