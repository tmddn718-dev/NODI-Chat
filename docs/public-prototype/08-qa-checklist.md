# QA 체크리스트

## A. 자동 검사(배포 전 필수)
```bash
npx tsc -b && npx vitest run && npm run build && bash scripts/check-secrets.sh
```
- [ ] 타입 검사·테스트·빌드 통과
- [ ] `check-secrets.sh` 통과(소스·히스토리·번들에 키 없음, 프런트 소스에 Groq·서버 비밀 변수 참조 없음, `.env` 미추적)

## B. 브라우저 네트워크 패널 수동 검증 (개발자 도구 → Network)
1. [ ] **Groq 직접 요청이 없다**: 필터 `groq` → 요청 0건. 자유 입력을 보내도 `/api/chat`(자기 도메인)만 보여요.
2. [ ] **응답·소스·번들에 키가 없다**: Sources에서 `GROQ`, `gsk_`, `service_role`을 검색 → 없음. `/api/health` 응답에는 `aiConfigured`(true/false)만.
3. [ ] **동의 전 PostHog 요청이 없다**: 저장소를 지우고(Application → Clear site data) 첫 진입 → 동의 안내만 보이고 `posthog`/`/capture/` 요청 0건. "동의하지 않고 사용"을 눌러도 0건.
4. [ ] **이벤트 payload에 민감정보가 없다**: 동의하고 한 흐름을 마친 뒤 `/capture/` 요청 본문 확인 → `properties`에 코드형 값만(이름·문장·일정 제목 없음). `$process_person_profile: false`, `$identify` 없음.
5. [ ] **철회 후 수집 중단**: 설정 → 철회하기 → 마지막으로 `analytics_consent_updated`(withdrawn) 1건만 가고, 이후 조작해도 `/capture/` 요청이 없다. `localStorage.nodi_anon_id`가 사라짐.
6. [ ] **세션 리플레이 없음**: PostHog 요청에 `$snapshot`(리플레이) 이벤트가 없다.
7. [ ] **피드백 자유 의견**: 제출 시 `/api/feedback`(자기 도메인)에만 본문이 있고, `/capture/`의 `feedback_submitted`에는 점수·태그·run_id만 있다. 제출 후 화면에 의견이 다시 보이지 않는다.

## C. 제품 흐름
- [ ] 선택지로 끝까지(조건 → 참석자 → 필수/선택 → 후보 → 시간 선택 → 확정)
- [ ] 자유 입력으로 조건 입력(예: "내일 오후에 김민지랑 30분") — 키가 설정된 환경에서
- [ ] 후보 없음 상황(범위를 오늘~내일로) → 안내 → 기간 확대/후보 새로 찾기
- [ ] 일부 충돌/참고 후보/조건 충돌 카드 표시, 필수 조건 불가 후보는 "확정 검토 불가"
- [ ] 확정 화면: "외부 캘린더 반영 전·초대 발송 전" 표시, 실제 메일·캘린더 동작 없음
- [ ] 피드백: 제출 / 건너뛰기 / 연타해도 1건 / 오류 시 재시도 / 이미 제출 안내
- [ ] 새로고침 후 같은 익명 ID·실험군 유지(`localStorage.nodi_anon_id` 동일), 철회 후 재동의하면 새 ID
- [ ] 테스트 데이터 초기화가 다른 방문자 화면에 영향 없음
- [ ] 한도: 분당 10회 초과 시 한국어 안내 + 다시 시도 가능 시점, 킬 스위치 시 점검 안내

## D. 반응형(모바일 375px · 태블릿 768px · 데스크톱 1400px)
- [ ] 동의 안내가 모바일에서 하단 시트로 열리고 두 버튼이 모두 보인다
- [ ] 참석자 선택(전체 화면 시트)·후보 카드·확정 모달·피드백 창을 한 손으로 끝까지 쓸 수 있다
- [ ] 가로 스크롤이 없고, 키보드가 열려도 입력창·버튼이 가려지지 않는다
- [ ] 화면을 돌리거나 창 크기를 바꿔도 `device_category` 이벤트 값이 같은 세션에서 바뀌지 않는다

## E. 접근성 기본
- [ ] 동의·피드백 창은 `role="dialog"`와 제목이 있고, 점수 선택은 `radiogroup`/`radio`
- [ ] 키보드(Tab·Enter·Esc)로 동의·피드백·참석자 선택을 조작할 수 있고 포커스가 보인다
- [ ] 상태는 색만이 아니라 아이콘·글자로도 전달된다, 대비 4.5:1 이상
